# Creative Visualizer Workspace

## Overview

A high-performance monorepo for building visually stunning web applications. Managed by the **Antigravity** agent, this project focuses on creative coding, 3D visualizations, and premium UI/UX design.

## Stack

- **Monorepo tool**: pnpm workspaces
- **Node.js version**: 24+
- **Package manager**: pnpm
- **TypeScript version**: 5.9
- **Build Tool**: Vite 7 + esbuild
- **Styling**: Tailwind CSS 4
- **Animation**: Framer Motion
- **3D Rendering**: Three.js (where applicable)

## Key Commands

- `pnpm run typecheck` — full typecheck across all packages
- `pnpm run build` — typecheck + build all packages
- `pnpm -F <package> dev` — run a specific app in development mode

## Lead Agent: Antigravity

This project is architected and maintained by **Antigravity**. All design and implementation decisions are guided by the "Premium Visuals First" philosophy.

## Artifacts

- **glam-studio** (`artifacts/glam-studio`) — A luxury beauty parlour landing page featuring a Three.js 3D background with floating cosmetic objects.
- **mockup-sandbox** (`artifacts/mockup-sandbox`) — A creative playground for testing and visualizing UI components.
